# Continuity Studio

أنشأه **محمد المرزوقي**، المعروف باسم **Burabeeh**، من دولة الإمارات العربية المتحدة.

[English](README.md) · [العربية](README.ar.md) · [Español](README.es.md) · [中文](README.zh-CN.md)

Continuity Studio هو نظام مفتوح المصدر لإنتاج الأفلام بالذكاء الاصطناعي وإدارة الاستمرارية. يحوّل فكرة الفيلم إلى مشروع محلي منظم يحتوي على القصة، ودليل الفيلم، والأصول البصرية، وأوراق الشخصيات والمواقع، ومشاهد القصة المصورة، وتسلسل اللقطات، وصياغة أوامر المنصات، وفحص الاستمرارية، والتصدير.

الهدف الأساسي هو الحفاظ على ثبات هوية الشخصيات والملابس والأدوات والحيوانات والمواقع والجغرافيا والإضاءة والأضرار بين المشاهد المولدة.

## مسار العمل

الفكرة ← المراجع ← القصة ← دليل الفيلم ← سجل الأصول ← أوراق الشخصيات والمخلوقات والحيوانات والمواقع والأدوات ← أصول المشاهد ← القصة المصورة وصورها ← تخطيط التسلسلات ← إطارات البداية والوسط والنهاية ← الأمر القياسي ← مترجم أوامر المنصة ← توليد الصور/الفيديو خارجياً عند الحاجة ← فحص الاستمرارية ← الموافقة ← التصدير.

## الميزات العاملة في الإصدار v1.0.0

- وضع الإنتاج الكامل ووضع المراحل مع الموافقة على كل مرحلة.
- أنماط AI First وReference First وHybrid قبل كتابة القصة.
- رفع مراجع محمية وربط صورة اختيارية بالشخصية الرئيسية دون استبدال الملف الأصلي.
- محرك القصة، ودليل الفيلم، و53 قاعدة تشغيل واستمرارية.
- معرّفات دائمة للأصول، وعلاقات، وإصدارات، وسجل نسب، وحالات موافقة وقفل.
- مهام حقيقية لإنشاء ملفات PNG محلية للمعاينة وأوراق الاستمرارية.
- أصول مشهد تعتمد على اكتمال الأصول وتحتوي على صورة رئيسية وبداية ووسط ونهاية.
- صور Storyboard منفصلة عن أصول المشهد.
- Canonical Prompt ومترجم أوامر Seedance وMiniMax وHiggsfield وGeneric.
- محرك وسوم يفصل المعرّف الداخلي مثل `CHAR_RASHID_001` عن الوسم المؤقت مثل `@Image 1`.
- محرك محلي دون اتصال، ونموذج محلي متوافق مع OpenAI اختيارياً، وإشراف Codex، وموفر OpenAI النصي اختيارياً.
- تخزين محلي بصيغ JSON وMarkdown ووسائط، وتصدير ZIP.
- مثبت Windows ونسخة محمولة.

## حالة المنصات بوضوح

- **OpenAI API:** تكامل نصي عامل ويتطلب `OPENAI_API_KEY`.
- **Codex:** إشراف عامل من خلال تسجيل الدخول إلى Codex/ChatGPT.
- **النموذج المحلي:** موفر نصي اختياري لخادم متوافق مع OpenAI.
- **Seedance 2.5:** ترجمة أوامر ووسوم مراجع وتصدير يدوي فقط؛ لا يوجد توليد مباشر عبر API.
- **MiniMax S2V-01:** اختيار مرجع وترجمة أوامر وتصدير يدوي فقط؛ لا يوجد API مباشر.
- **Higgsfield:** خطة مراجع وأمر مخصص وتصدير يدوي فقط؛ لا يوجد API مباشر.
- **KimiBrain:** فكرة مستقبلية وغير مدمجة في هذا الإصدار.
- **الصور المحلية:** مولد PNG للمعاينة البصرية وليس نموذج صور واقعية.

لا توجد رعاية أو شراكة أو مصادقة رسمية من الشركات المذكورة.

## التثبيت عبر سطر الأوامر باللغة العربية

المتطلبات: Node.js 20.19 أو أحدث (يُنصح بـ Node.js 22 LTS)، وnpm 10 أو أحدث، وGit عند الاستنساخ. لا يحتاج الإصدار الحالي إلى Python أو FFmpeg أو قاعدة بيانات خارجية.

```bash
git clone https://github.com/momorzq-oss/Continuity-Studio.git
cd Continuity-Studio
npm run setup -- --lang ar
npm run desktop:dev
```

يمكن استخدام `--yes` للإعداد غير التفاعلي: `npm run setup -- --lang ar --yes`.

يقوم المثبت بفحص Node.js، ويسأل عن تثبيت الحزم، وإنشاء `.env` من الملف النموذجي، وتشغيل فحص الأنواع والاختبارات. لا يطلب أي مفتاح سري ولا يطبعه. راجع [دليل المستخدم](docs/i18n/ar/USER_GUIDE.md) إلى جانب دليل التثبيت والبدء السريع.

راجع [دليل التثبيت العربي](docs/i18n/ar/INSTALLATION.md) و[البدء السريع](docs/i18n/ar/QUICK_START.md). يمكن تنزيل مثبت Windows أو النسخة المحمولة من صفحة GitHub Releases. الحزم غير موقعة رقمياً حالياً وقد يعرض Windows تحذير الناشر غير المعروف.

## استخدام سريع

1. أنشئ مشروعاً وحدد الفترة ونسبة العرض والمدة ووضع القصة.
2. ارفع مراجع اختيارية وحدد الأدوار؛ يمكن تعليم صورة واحدة كمصدر للشخصية الرئيسية.
3. أكمل إعداد المراجع ثم شغّل Production Agent.
4. راجع القصة ودليل الفيلم وسجل الأصول.
5. أنشئ صور الأصول والأوراق ثم وافق عليها واقفل النسخة المختارة.
6. أنشئ أصول المشاهد وStoryboard والتسلسلات وإطارات START/MID/END.
7. افتح Prompt Compiler وافحص وسوم المراجع وحدود النموذج.
8. أصلح مشاكل الاستمرارية ثم صدّر المشروع.

## الهوية المستقلة عن المنصة

المعرّف `CHAR_MAIN_001` ملك لمشروع Continuity Studio. أما `@Image 1` فهو وسم مؤقت لطلب Seedance واحد. يحفظ النظام الهوية الدائمة ثم ينشئ الوسم المطلوب لكل منصة دون تغيير الأصل.

## الخصوصية والأمان

يتم تخزين المشاريع والمراجع والوسائط محلياً وهي مستبعدة من Git. ضع مفاتيح الخدمات في `.env` المستبعد ولا ترفع الصور الشخصية أو المشاريع الخاصة أو السجلات إلى مستودع عام.
