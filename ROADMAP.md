# Roadmap

These are possible future directions, not completed features or promises:

- Direct, tested image-provider adapters.
- Direct, tested video-provider adapters.
- More local text, image, and video model support.
- Automatic visual continuity inspection.
- Audio production and voice-continuity tools.
- Timeline editing and final film assembly.
- Collaborative filmmaking and optional cloud project storage.
- Public plugin/provider SDK.
- macOS and Linux desktop packaging.
- Full application-interface localization beyond the multilingual docs and CLI installer.
