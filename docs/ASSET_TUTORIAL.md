# Asset Tutorial

Continuity Studio supports characters, creatures, animals, locations, props, wardrobe, vehicles, and extended prop categories such as weapons/tools/environments through the asset registry.

For each asset you can upload an existing visual reference, use the local previsual renderer, generate adaptive sheet views, review, approve, lock, and reuse the stable ID across sequences. A record stores locked/mutable traits, state, provider/model, source references, master/thumbnail paths, jobs, version, and lineage.

Recommended flow:

1. Finish Story and Film Bible.
2. Generate Asset Manifest.
3. Upload or assign preferred sources.
4. Preview the generation queue; external paid adapters must require approval.
5. Generate one asset or **Generate all assets**.
6. Inspect master and sheet views.
7. Reject/edit prompt/change references/retry when needed.
8. Approve then lock the chosen version.
9. Create a new version for later changes; never silently replace a locked asset.
