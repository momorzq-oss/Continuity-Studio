# Complete Movie Tutorial — The Last Camp

This fictional demonstration contains no private references.

**Premise:** In 1965, a traveller named Rashid crosses the UAE desert with one camel and finds a mysterious Bedouin camp.

1. Create a six-minute Emirati desert horror project, 12 sequences, 2.39:1, Full or Phases mode.
2. Optionally upload a fictional/main-character source; otherwise use AI First.
3. Generate Story: Rashid, Old Man, Woman, Boy, the Presence, desert route, camp, and camp edge.
4. Approve Film Bible: period, world law, visual language, identity/geography rules.
5. Generate Asset Manifest: cast, camel, tack, wardrobes, dallah, campfire, practical light, travel kit, and locations.
6. Generate character/animal/location/prop masters and continuity sheets; approve/lock.
7. Generate 12 Scene Assets with master plus START/MID/END images.
8. Generate 36 separate storyboard frames.
9. Review 12 timed sequences and 36 continuity anchors.
10. Compile four platform profiles per sequence. Inspect permanent IDs, temporary tags, upload order, settings, warnings, and any MiniMax critical-limit blocker.
11. Run Continuity Inspector, resolve blocking issues, approve, and export the project ZIP.

Regenerate the safe demo locally with `npm run demo:create`. The resulting `data/` project is intentionally ignored and is not published to GitHub.
