# Main Character Reference Tutorial

1. Create a project and choose **AI First**, **Reference First**, or **Hybrid**.
2. Open **Reference Setup**.
3. Add a PNG/JPEG/WebP image, enter the character name, choose Character, and enable **Main character source**.
4. Assign Identity and any additional roles, keep Story usage Required, then complete setup.
5. Generate Story. The uploaded identity becomes the one protagonist (`CHAR_MAIN_001`), linked to protected source `CHAR_MAIN_001_SOURCE`; duplicate lead proposals are reconciled.
6. Generate Assets. The uploaded original remains unchanged while generated master/sheet views are stored as separate files/lineage.
7. Review the master and adaptive continuity views. Approve, then lock.
8. Generate Scene Assets and storyboard frames.
9. Compile platform prompts and confirm the Identity reference remains included and first-priority.

An identity lock means face/age/body/hair/wardrobe traits and the protected source cannot be silently redesigned. Regeneration creates a new version; it does not overwrite the source.
