# Continuity Studio v1.0.0

The first public release of **Continuity Studio By BURABEEH**, created by Mohammed Al Marzooqi in the United Arab Emirates.

## Highlights

- Full and phase-by-phase production-agent modes.
- AI First, Reference First, and Hybrid pre-story setup.
- Story Engine, Film Bible, 53 operational rules, and continuity validation.
- Stable asset identities, lineage, versions, approvals, and locks.
- Local PNG previsualization for assets, continuity sheets, scenes, and storyboards.
- Scene dependency planning with master and START/MID/END images.
- Canonical prompt compiler and provider-independent reference tagging.
- Editable Seedance, MiniMax, Higgsfield, and Generic model profiles.
- Local, Codex-supervised, hybrid, and optional OpenAI text brains.
- Local project storage and structured ZIP export.
- English, Arabic, Spanish, and Simplified Chinese setup and usage documentation.

## Windows downloads

- **NSIS installer:** guided per-user installation with optional install directory.
- **Portable:** standalone executable with no installer.

These community binaries are not commercially code-signed. Windows may show an unknown-publisher warning. Download only from this official GitHub release.

## Provider boundaries

OpenAI text integration and Codex supervision are functional when configured. Seedance, MiniMax, and Higgsfield are manual prompt/reference export targets in v1.0.0; Continuity Studio does not claim direct generation APIs for them. The built-in image renderer creates production previsualization PNGs, not photorealistic output.
