# Continuity Studio v1.0.1

Continuity Studio By BURABEEH v1.0.1 completes the protected reference-image workflow across New Project, Reference Manager, Assets, and generated sequences.

## Highlights

- JPG, JPEG, PNG, and WebP reference uploads with immediate previews.
- Main-character reference-first setup with a nine-view identity sheet.
- Optional references for characters, creatures, locations, vehicles, props, weapons, animals, costumes, accessories, objects, style, composition, and lighting.
- Versioned replacement, removal, persistence after reopening, and per-sequence reference assignment.
- Dedicated Assets workspace with generated sheets, approval, locking, errors, and retry.
- Offline reference-derived PNG generation plus optional OpenAI image generation when configured.
- Protected source files remain separate from generated assets.
