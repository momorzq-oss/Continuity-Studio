# Continuity Studio By BURABEEH v1.1.0

v1.1.0 advances Continuity Studio from the original eight-phase planner into a visual, versioned production workspace through final prompt/reference packaging.

## Highlights

- Visual Movie DNA: 27 categories, 629 options, comparisons, master frame, lock/version state, and Global Location DNA.
- Story v2: Full Story, Structure, Timeline, Character Arcs, Sequence Breakdown, scoped edits, impact analysis, approval, and locking.
- Permanent production memory: Film Bible, Character Analysis, protected references, character sheets/states, Asset Manifest, and Image Asset Library.
- Full Script v2: screenplay, dialogue, shot, production, scene, and sequence views with exact dialogue records.
- Sequence Workspace v3: Previous/Next navigation, synchronized Normal/JSON prompts, validation, overrides, saved versions, optional Storyboard Grid, and persistence.
- Eight versioned Platform Profiles: Seedance, Higgsfield, MiniMax, Veo, Kling, Runway, Sora, and Custom.
- Reference Tagging Engine: stable IDs, project image numbers, provider slots, `@Image` numbering, upload order, and sequence packages.
- AI Filmmaking Visual Guide principles integrated as durable production knowledge instead of provider-specific global limits.
- 57 real current-build screenshots and expanded installation, workflow, user, troubleshooting, architecture, and roadmap documentation.

## Provider boundary

Platform Profiles compile and validate manual provider handoffs. v1.1.0 does not make direct Seedance, Higgsfield, MiniMax, Veo, Kling, Runway, or Sora video API calls.

Generated-video import, automatic video inspection, attempt approval, targeted video regeneration, automatic approved END-to-START transfer, production dashboard, and final movie assembly remain planned work.
