# Scene and Storyboard Tutorial

A **Scene Asset** is the reusable visual definition of one sequence composition. It contains a master plus START, MID, and END images. A storyboard frame is a separate shot-facing derivative.

1. Complete visual assets and Sequence Planning.
2. Plan Scene Assets. Each scene records required asset/location IDs.
3. Resolve any missing-dependency blockers.
4. Generate master/START/MID/END.
5. Review geography, identity, props, screen direction, and light.
6. Approve/lock externally as the workflow requires.
7. Generate storyboard frames separately.

Assets repeat when continuity requires them. Completed scene imagery should not accidentally repeat for a changed composition: unchanged dependencies reuse the scene; changed dependencies increment the scene version and invalidate its current images/storyboards. Regeneration records new jobs and lineage rather than hiding history.
