# البدء السريع

1. ثبّت التطبيق أو شغّل `npm run setup -- --lang ar` ثم `npm run desktop:dev`.
2. أنشئ مشروعاً وحدد Full أو Phases وAI First أو Reference First أو Hybrid.
3. في Reference Setup ارفع PNG/JPEG/WebP اختيارياً وحدد الأدوار. علّم صورة الشخصية الرئيسية عند الحاجة.
4. أكمل الإعداد وشغّل Production Agent.
5. راجع Story وFilm Bible ثم أنشئ الصور والأوراق في Assets.
6. أنشئ Scene Assets ثم Storyboard.
7. راجع Sequences وإطارات START/MID/END.
8. في Prompts اختر المنصة وافحص المراجع والوسوم والمشكلات المحظورة. التصدير إلى Seedance/MiniMax/Higgsfield يدوي.
9. شغّل Continuity Inspector ثم صدّر ZIP.
