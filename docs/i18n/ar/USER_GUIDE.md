# دليل المستخدم بالعربية

## المشروع والأوضاع

تغذي فكرة الفيلم جميع المراحل. ينفذ وضع **Full** المسار تلقائياً، بينما ينتظر وضع **Phases** الموافقة بعد كل ناتج رئيسي. يمكن تغيير الوضع عندما لا يكون الوكيل قيد التشغيل.

### الوضع التلقائي

عند اختيار **AUTOMATIC MOVIE** أدخل وصف الفيلم والمدة واللغات وتفضيل البطل، ثم اضغط **CREATE MY MOVIE**. يختار Studio Brain نظام Movie DNA وPlatform Profile، وينشئ Story وFilm Bible وتحليل الشخصيات، ثم يتوقف عند نقطة فحص هوية البطل. ارفع صورة هوية محمية وأنشئ ورقة شخصية محايدة، أو اختر بطلاً خيالياً مولداً بالذكاء الاصطناعي. يحفظ التطبيق كل مرحلة وقرار، ويدعم Pause وResume وStop وManual Override والاستئناف بعد إعادة التشغيل.

### الوضع اليدوي الموجّه

عند اختيار **MANUAL PRODUCTION** تبدأ شاشة **DESCRIBE YOUR MOVIE** البسيطة. أدخل عنواناً اختيارياً، وصفاً موجزاً، المدة التقريبية، لغة الفيلم، لغة الحوار، ومنصة مفضلة اختيارية، ثم اضغط **NEXT**. يحلل Studio Brain الوصف ويملأ إعدادات المشروع وVisual Movie DNA بتوصيات قابلة للتعديل، لكنه لا يعتمدها تلقائياً.

يعرض شريط دائم 14 مرحلة من Brief إلى Export. استخدم **BACK** و**SAVE** و**NEXT** و**APPROVE AND NEXT** و**LOCK AND NEXT**. إذا نقص مطلب أساسي يتوقف NEXT ويذكر السبب المحدد. عند إعادة فتح المشروع تظهر **CONTINUE WHERE YOU LEFT OFF** مع **RESUME** و**VIEW PROJECT**. يمكن التبديل بين الوضع اليدوي والتلقائي مع الاحتفاظ بكل البيانات والاعتمادات والمراجع.

## المراجع قبل القصة

يتيح AI First للنظام التصميم أولاً، ويجعل Reference First الصور قيوداً للقصة، بينما يقفل Hybrid الهويات المهمة ويترك مساحة للتوسّع. لا يتغير الملف الأصلي، وتُسجل أدواره وأولويته ونسبه. ويمكن ربط مرجع رئيسي بهوية البطل الدائمة.

## القصة ودليل الفيلم والقواعد

تحدد Story السرد، ويقفل Film Bible العالم واللغة البصرية والحدود، وتحول Rules مبادئ الاستمرارية إلى فحوص قابلة للتنفيذ. يجب توثيق سبب أي تجاوز.

## الأصول والمشاهد والقصة المصورة

تحصل الشخصيات والمخلوقات والمواقع والأدوات على معرّفات ثابتة وإصدارات وحالات موافقة. اقفل النسخ المعتمدة قبل إنشاء المشاهد. ينتج Scene Assets صورة رئيسية وحالات START/MID/END، بينما يبقى Storyboard طبقة لقطات منفصلة. ينشئ التجديد الإجباري نسخة جديدة.

## التسلسلات والأوامر والاستمرارية

ينظم Sequence Planner الوحدات الزمنية، وتوفر Sequence Workspace v3 محرري Normal وJSON المتزامنين مع الإصدارات وترقيم المراجع. تستخدم ملفات Seedance وHiggsfield وMiniMax وVeo وKling وRunway وSora في الإصدار v1.1.0 التصدير اليدوي وليس API مباشراً. يجب حل المشكلات المانعة قبل التصدير.

## التصدير والخصوصية

يحتوي ZIP على JSON وMarkdown ووسائط المشروع. يستبعد Git مجلد `data/` وملف `.env` والسجلات والمراجع المرفوعة والوسائط المولدة. افحص الحزمة دائماً قبل مشاركتها.
