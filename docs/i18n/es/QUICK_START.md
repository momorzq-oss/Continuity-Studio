# Inicio rápido

1. Instala la aplicación o ejecuta `npm run setup -- --lang es` y `npm run desktop:dev`.
2. Crea un proyecto y elige Full/Phases y AI First/Reference First/Hybrid.
3. En Reference Setup añade PNG/JPEG/WebP opcionales, roles y una fuente de personaje principal si procede.
4. Completa la preparación y ejecuta Production Agent.
5. Revisa Story/Film Bible y genera activos/hojas.
6. Genera Scene Assets y Storyboard.
7. Revisa secuencias y estados START/MID/END.
8. En Prompts selecciona plataforma, revisa referencias/etiquetas/bloqueos y exporta manualmente a Seedance, MiniMax o Higgsfield.
9. Ejecuta Continuity Inspector y exporta el ZIP.
