# 中文快速入门

1. 运行 `npm run setup -- --lang zh`，然后运行 `npm run desktop:dev`。
2. 完成首次设置。离线使用可选择内置 Local Brain。
3. 点击 **New movie project**，填写创意、类型、时代、格式和时长。
4. 选择 **Full** 自动运行全部阶段，或选择 **Phases** 在每一阶段审批。
5. 在 Reference Setup 中选择 AI First、Reference First 或 Hybrid，并添加需要保护的参考图。
6. 点击 **Complete setup**，然后在 Production Agent 中发送制作要求。
7. 依次检查 Story、Film Bible、Assets、Characters、Scene Assets 和 Storyboard。
8. 锁定已批准资产，规划场景，并生成 START/MID/END 图像。
9. 在 Prompt Compiler 中选择模型配置并编译。Seedance、MiniMax、Higgsfield 输出需要手动复制到相应平台。
10. 在 Continuity Inspector 中处理阻断问题，最后导出 ZIP。

本地 PNG 是结构化预可视化素材，不代表照片级 AI 图像。项目数据位于本机 `data/`，并被 Git 忽略。
