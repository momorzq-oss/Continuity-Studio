# Frame Rules

## Three Anchor States

Every planned sequence should support:

START FRAME
MID FRAME
END FRAME

These are continuity anchors.

They do not require three generated still images when the workflow does not need them.

## Start Frame

Define:

- Location
- Time
- Characters
- Character count
- Character positions
- Body orientation
- Screen direction
- Wardrobe
- Injuries
- Props
- Creature state
- Animal state
- Vehicle state
- Camera
- Lens
- Composition
- Lighting
- Colour
- Weather
- Motion state
- Emotional state

The START state must reconcile with prior approved continuity.

## Mid Frame

Define the major state change.

Track:

- Movement
- New information
- Performance
- Threat
- Camera development
- Object transfer
- Damage change
- Position change
- Emotional change

Do not allow the mid state to violate locked assets.

## End Frame

Define the exact intended handoff.

Track:

- Final character positions
- Final screen direction
- Wardrobe
- Injuries
- Props
- Creature state
- Animal state
- Vehicle state
- Location
- Camera relationship
- Lighting
- Weather
- Story information
- Motion
- Emotional state

## Frame Prompt

A frame prompt should separate:

1. Locked visual references
2. Current physical state
3. Composition
4. Camera and lens
5. Lighting and colour
6. Action frozen at this instant
7. Negative continuity constraints

## End-to-Start Rule

The next START state derives from the previous approved END_STATE.

It does not have to use the exact previous image pixel-for-pixel.

The transition planner decides whether the next sequence is:

- Direct continuation
- Match continuation
- Controlled time jump
- Controlled location transition
- New angle preserving physical state

Any discontinuity must be explicit.
