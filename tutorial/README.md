# Continuity Studio By BURABEEH Tutorial

This folder contains a real-interface tutorial production for the isolated demo project **The Fire Beyond the Dunes — Tutorial Demo**.

## Deliverables

- `continuity-studio-full-tutorial.mp4` — 10–20 minute guided workflow
- `continuity-studio-quick-start.mp4` — 3–5 minute condensed workflow
- `continuity-studio-social-demo.mp4` — 30–60 second overview
- `voiceover-script.txt` — full, quick, and social narration
- `tutorial-script.md` — editorial and accuracy plan
- `tutorial-shot-list.md` — capture-to-chapter mapping
- `tutorial-chapters.json` — machine-readable edit plan
- `thumbnail.png` — 1280×720 tutorial artwork built from the real dashboard

Narration must use the user-selected voice. Captions must be generated from the finished narration audio with Whisper before they are burned into the videos. The `work/` folder contains temporary verification media and the large project export and is intentionally excluded from Git.
