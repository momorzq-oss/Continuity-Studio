# Continuity Studio By BURABEEH — Guided Tutorial

This production script uses only the real local application and the isolated project **The Fire Beyond the Dunes — Tutorial Demo**. Existing user projects are never opened for editing. Waiting screens are removed; repeated asset and sequence operations are compressed.

## Presentation language

- 1920×1080, 30 fps, clean chapter cards, subtle push-ins, and a high-contrast cursor marker.
- Keep interface text sharp; zoom only when the selected control would otherwise be small.
- Use calm professional narration. Burn Whisper-timed tutorial captions after narration is final.
- Tutorial captions are production media and are unrelated to the movie project's subtitle toggle.
- Show no API keys, tokens, terminal windows, personal folders, or non-tutorial project content.

## Full tutorial flow

| Chapter | Interface action | Teaching result |
|---|---|---|
| Opening | Establish the real app brand and isolated tutorial project | Viewer understands scope and privacy boundary |
| Project Setup | Complete title, idea, runtime, sequence duration, delivery, audio, language, and platform fields | Viewer understands sequence calculation and Full versus Phases |
| Reference-first Setup | Upload fictional Rashid reference and generate the character sheet | Original identity remains protected |
| Movie DNA | Browse, compare, accept a recommendation, review the board, generate master frame, and lock V1 | Visual direction becomes canonical without replacing identity |
| Story | Show the three creation methods, generate, review, approve, and lock | Story becomes the narrative source of truth |
| Film Bible | Review world law and approve/lock | Durable production facts become downstream constraints |
| Characters and Assets | Analyze cast, inspect states, build the manifest, generate, regenerate, approve | Permanent flat numbering and version history are demonstrated |
| Timeline, Continuity, Audio | Show timed events, voice locks, and central state memory | Viewer understands history versus current state |
| Full Script | Review screenplay, dialogue, production views, voice identity, and script lock | Exact dialogue remains protected from shot edits |
| Shot and Sequence Planning | Inspect 60 timed shots and 15 sequences; lock Sequence 01 plan | Timing and dependency gates are clear |
| Sequence Workspace v3 | Compile Normal and JSON, validate, switch Seedance/Veo, inspect Storyboard Grid | One Prompt State drives synchronized platform views |
| References and Rules | Inspect @Image mapping and download reference package | Permanent IDs are distinguished from temporary upload order |
| Generated Video Return | Import, reject, import corrected attempt, approve and lock | Attempt history and targeted regeneration are clear |
| Dashboard and Export | Show 15/15 approved, ledger, zero open continuity warnings, and export screen | Viewer sees a complete production outcome |
| Closing | Summarize Full and Phases | Viewer knows how to begin a real project |
