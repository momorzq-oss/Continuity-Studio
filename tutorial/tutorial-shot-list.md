## Cursor and callout treatment

- Cursor begins outside the content region, moves to the control being discussed, and rests before click emphasis.
- Use an amber ring for selectable controls, green for approved/locked results, and red only for validation or rejection.
- Never cover field labels or status values with the cursor.
- Chapter titles appear for 1.5 seconds in the upper-left safe area.
- For small records, crop no tighter than 70% of the original interface so navigation context remains visible.
